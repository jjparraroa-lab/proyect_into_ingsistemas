## Descripción del Proyecto
Este proyecto nace de la salida de campo al CLENA, en la Aduana de Barranquilla. Durante la visita observamos la Biblioteca y encontramos una situación relacionada con la gestión de alertas y avisos:cómo se informa a los usuarios sobre fechas de devolución de libros, disponibilidad de materiales.

Actualmente, no hay un sistemas de alertas establecido para avisar la disponibilidad exacta de libros, si estan en fisico o digital. Esto genera dificultades como retrasos, carga de trabajo para el personal, etc. Esto afecta a usuarios visitantes, personal bibliotecario y administradores.

El objetivo del proyecto es comprender esta situación, formularla como un problema claro y proponer una posible solución tecnológica que ayude a mejorar cómo se generan, comunican y gestionan las alertas dentro de la biblioteca. Como indica el laboratorio, no se desarrollará el software, sino que se documentará el análisis y la propuesta.
